# Ник аккаунта и анимация заголовка в стиле nvim

## 1. Ник (handle)
- Миграция `migrations/0003_handle.sql`: `ALTER TABLE users ADD COLUMN handle TEXT;` + `CREATE UNIQUE INDEX users_handle ON users(handle);`
- Формат: `^[a-z0-9_-]{3,24}$` (нижний регистр), запрещённые: admin, root, api, support, finance, financelog, system.
- При создании пользователя ник предлагается автоматически: Telegram username → иначе часть email до `@` → иначе `user-<6 символов>`;
  нормализовать (lower, недопустимые символы → `-`, обрезать до 24); при занятости — добавлять `-2`, `-3`…
  Для уже существующих пользователей без ника — назначить так же при следующем `/api/me`.
- `GET /api/me` возвращает `user.handle`. `PATCH /api/me {handle}` (CSRF как у POST) → 200 / 400 `bad_handle` / 409 `handle_taken`.
- Box «аккаунт»: строка `-- ник: @glupismeshon [изменить]` → инлайн-поле с префиксом `@` и кнопками `[сохранить] [отмена]`, ошибки текстом.
- Тесты: нормализация и проверка формата (чистые функции в worker/util.js).

## 2. Анимация заголовка (бренд в топбаре)
Как в nvim: блочный курсор `▊`, команда `dd` удаляет строку, затем «набирается» новый текст.
Последовательность при запуске приложения (один раз за загрузку страницы):
1. `finance.log▊` — курсор мигает 2 раза (как сейчас мигает).
2. справа от текста появляется `dd` цветом --muted (как отображение набранной команды), 350 мс → текст стирается (мгновенно, как удаление строки), `dd` исчезает.
3. посимвольно набирается `запиши в меня` (en: `write me down`) — 55–75 мс на символ со случайным разбросом, курсор после последнего символа; пауза 1,2 с.
4. `dd` → стирание → набирается `ахахахаха` (en: `hahahahaha`); пауза 1 с.
5. `dd` → стирание → набирается финал: `finance.log@<handle>` если вошёл, иначе `finance.log`. Курсор продолжает мигать. Часть `@handle` — цветом --muted.
- Во время анимации ширина топбара не прыгает (min-width на контейнер бренда не нужен, но правая часть топбара не должна сдвигаться — бренд занимает свободное место, overflow: hidden, text-overflow: ellipsis).
- На мобильном если `finance.log@handle` не помещается — показывать `fl@handle`.
- `prefers-reduced-motion: reduce` → сразу финальный текст без анимации.
- Настройка в `$ подсказки`-подобном box `$ анимация` (или внутри существующего box «тема»): `[✓] анимация заголовка` (по умолчанию вкл) — хранится в money.log.settings.titleAnim.
- Клик по бренду — проигрывает анимацию заново (если включена).
- Если `/api/me` ответил позже начала анимации — финальная строка всё равно должна взять ник (дождаться ответа максимум 3 с перед финальным шагом).
- `aria-label` бренда всегда «finance.log»; анимированный текст `aria-hidden="true"`.
