# Разбивка баланса: свои деньги, копилки, кредитки, кредиты

## Логика (views.js)
`breakdown(state)` → `{own, savings, creditCards, loans, other, views:{all, noLoans, noCards, ownOnly, loansOnly}}`:
- own = Σ остатков счетов debit + cash; savings = Σ savings («копилки»); creditCards = Σ credit_card (обычно ≤ 0);
  loans = Σ loan (≤ 0 — долг); other = person (долги людей: + нам должны, − мы должны).
- views (варианты итога):
  - `all` — всё: own + savings + creditCards + loans;
  - `noLoans` — без кредитов: own + savings + creditCards;
  - `noCards` — без кредиток: own + savings + loans;
  - `ownOnly` — без кредитов и кредиток: own + savings.
  - `loansOnly` — кредитки и кредиты: creditCards + loans (долг со знаком минус).
- Архивные счета учитываются (как сейчас). person не входит ни в один вариант (как сейчас), показывается отдельной строкой.
- Тесты: сценарий дебет 50 000, наличные 3 000, копилка 20 000, кредитка −12 000, кредит −300 000.

## Интерфейс (box «$ остаток»)
- Заголовок `$ остаток [всё]` — кнопка с циклом `[всё] → [свои] → [кредиты] → [всё]`
  (en: `$ balance [all] → [own] → [loans]`). Клик по заголовку или метке, Enter и пробел переключают режим.
  Выбор хранится в `balanceView`: `all`, `ownOnly`, `loansOnly`; по умолчанию `all`.
  Старые настройки `noLoans` / `noCards` переходят в `all`; старые вычисляемые представления остаются совместимыми.
  Переключатель доступен и без кредитов: их сумма равна нулю.
- В режиме `all` разбивка скрыта. В `ownOnly` под суммой две строки: свои деньги и копилки;
  в `loansOnly` — кредитки и кредиты. Нулевые строки также видны; отрицательные суммы — цвет --over.
  Доходы/расходы остаются ниже. Долги людей по-прежнему доступны в списке счетов и не входят в баланс.
- Итог на экране счетов и прогноз используют выбранный режим, включая `loansOnly`.
- Счета на экране «счета» группируются: `-- свои` / `-- копилки` / `-- кредитки` / `-- кредиты` с подитогами.
- При добавлении счёта в select вида появляются «кредит» (loan) и подсказка: для кредитки и кредита начальный остаток вводится как долг
  (минус подставляется автоматически, кнопка [± минус] остаётся).
