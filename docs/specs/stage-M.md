# Этап M — мобильный интерфейс (iPhone)

Десктоп (≥ 900px) и планшет не ломать. Всё ниже — для ширины < 600px (и для режима standalone на iPhone).
Стиль init.Tasks (токены из design.md) сохраняется. dist/core/* не трогать.

## Баги со скриншотов iPhone (обязательно)
1. Топбар залезает под статус-бар (meta `black-translucent` + viewport-fit=cover). Топбар: `padding-top: env(safe-area-inset-top)`,
   высота = 44px + inset; контент ниже сдвигается на ту же величину. Фон топбара непрозрачный --bg (никакого blur с просвечиванием текста).
2. `<input type="date">` вылезает за правый край в Safari iOS: `-webkit-appearance:none; appearance:none; min-width:0; width:100%; box-sizing:border-box; display:block; text-align:left`,
   а для `::-webkit-date-and-time-value { text-align:left; }`.
3. Подсказку «N новая запись · Esc отмена» скрыть на тач-устройствах: `@media (hover:none) and (pointer:coarse)`.

## Новая раскладка < 600px
- **Топбар**: `[f] money.log▊` слева, справа только `[тёмная]/[светлая]`. Дата скрыта.
- **Нижняя панель вкладок** (fixed bottom, высота 56px + `env(safe-area-inset-bottom)`, фон --bg, верхняя граница 1px --border):
  4 кнопки с иконкой (инлайн-SVG Lucide, 18px) и подписью 11px: `журнал`, `счета`, `планы`, `ещё`.
  Активная — цвет --accent. «счета» и «планы» пока ведут на экран-заглушку в стиле лога:
  `$ счета` / `[--] появится на этапе 1` (для планов — «на этапе 4»).
  Верхнее меню-вкладки (журнал/удалённые/скачать/восстановить) на мобильном скрыть.
- **Экран «журнал»** сверху вниз:
  1. box «$ остаток»: сумма, `[ok] доходы`, `[--] расходы` — компактнее (сумма 34px, отступы меньше), строку «начальный остаток» оставить.
  2. Две большие кнопки в ряд, высота 52px, на всю ширину: **`+ пришло`** (primary, accent) и **`− ушло`** (ghost с цветом --text, рамка --border).
  3. box «$ журнал»: фильтры `[все] [расходы] [доходы]` горизонтальной строкой со скроллом без полосы, поиск — иконка-лупа, по нажатию раскрывается поле. Список операций как сейчас.
  Box «$ новая запись» на мобильном на странице НЕ показывать.
- **Форма-шторка** (bottom sheet): по нажатию `+ пришло` / `− ушло` (и при «изменить» у записи) выезжает снизу
  (transform translateY, 220ms, без анимации при prefers-reduced-motion), затемнение фона rgba(0,0,0,.6), закрывается свайпом-вниз не нужно — достаточно `[×]` сверху справа, тапа по фону и Escape.
  Внутри: заголовок-label `$ пришло` / `$ ушло` / `$ изменить`; поле суммы крупное (28px, `inputmode="decimal"`, автофокус, чтобы сразу открылась клавиатура);
  заметка; дата одной строкой `// дата: сегодня [изменить]` — по нажатию показывается поле date; большая кнопка «записать» (52px).
  Переключатель расход/доход внутри шторки оставить (на случай ошибки выбора). Шторка учитывает `env(safe-area-inset-bottom)`.
  Реализация: переиспользовать существующую форму (#entry-form и её id), на мобильном переносить её в шторку CSS-ом/классом, а не дублировать разметку — чтобы логика app.js осталась одна.
- **Экран «ещё»**: box `$ данные` — `[↓ скачать копию]`, `[↑ восстановить копию]`, строка `// хранится на этом устройстве`;
  box `$ удалённые` — переход к списку удалённых (существующий режим trash), с счётчиком;
  box `$ о приложении` — `money.log v0.2`.
- Размер тач-целей ≥ 44px. Все кнопки-«скобки» на мобильном с увеличенными полями.
- Нижний отступ контента = высота таб-бара + inset, чтобы последняя запись не пряталась под панелью.
- Тост поднимается над таб-баром.

## Состояние
- Текущая вкладка — в памяти (переменная), при перезагрузке — «журнал». Хеш-роутинг не нужен.
- На десктопе всё как сейчас (box «новая запись» в правой колонке). Кнопки «+ пришло / − ушло» на десктопе можно тоже показать над формой — не обязательно.
