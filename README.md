# finance.log (v0.3)

Первый прототип личного финансового журнала в терминальном стиле.

## Для первого теста

Нужен только современный браузер. Откройте приложение, задайте начальный остаток при необходимости, затем внесите доход или расход. Сумма обязательна; заметка необязательна; дата по умолчанию сегодняшняя.

Контрольный пример: начальный остаток 10 000 ₽, доход 2 000 ₽, расход 320,50 ₽ → остаток 11 679,50 ₽.

## Что работает

- Один общий остаток в рублях.
- Запись дохода и расхода с датой и заметкой, без категорий.
- История, поиск, фильтр по типу операции.
- Редактирование, удаление в отдельный раздел и восстановление.
- Начальный остаток не считается доходом.
- Сохранение после перезагрузки, тёмная и светлая темы.
- JSON-копия и восстановление с пропуском совпадающих ID.
- Нажмите N (или Т в русской раскладке), чтобы перейти к новой записи.

## Где данные

Записи сохраняются в localStorage текущего браузера для адреса приложения. Они не отправляются на сервер. Другой браузер, устройство или другой адрес приложения имеет отдельный журнал. Очистка данных сайта удаляет журнал; регулярно скачивайте копию. Закрытый режим браузера не подходит для постоянного хранения.

Резервная копия содержит суммы и заметки обычным текстом. При восстановлении новые ID добавляются, существующие не перезаписываются. Начальный остаток импортируется только в пустой журнал с нулевым начальным остатком. Удалённые записи входят в копию.

Этот прототип не шифрует журнал и не синхронизирует его между устройствами. Пользуйтесь одной активной вкладкой для ввода. Ожидаемые будущие операции пока не поддерживаются.

## На iPhone

Версия 0.2: на узком экране (< 600px) внизу вкладки «журнал / счета / планы / ещё». Кнопки «+ пришло» и «− ушло» открывают форму снизу (шторкой); закрыть можно [×], тапом по фону или Escape. «Счета» и «планы» пока заглушки. Копия, восстановление и удалённые — на вкладке «ещё».

1. На Mac в папке проекта запустите `npm run start:lan`.
2. Узнайте IP Mac командой `ipconfig getifaddr en0`.
3. Телефон и Mac должны быть в одной Wi-Fi сети. На iPhone откройте в Safari `http://<IP>:8765`.
4. Нажмите «Поделиться» → «На экран „Домой“».

Важно: по обычному http офлайн-режим не работает, потому что service worker требует HTTPS. Он заработает после публикации на HTTPS-хостинге.

Данные хранятся отдельно на каждом устройстве и адресе. Перед сменой телефона или адреса делайте копию через «Скачать копию».

## Запуск исходников на Mac

В папке проекта выполните `npm start` (нужен Python 3). Откройте http://127.0.0.1:8765 в браузере. Никаких зависимостей устанавливать не требуется.

Альтернатива без Node: `python3 -m http.server 8765 --bind 127.0.0.1 --directory dist`.

Проверки расчётов: `npm test` (нужен Node.js).

## План

1. **Эта версия:** проверить удобство повседневной записи и правильность остатка.
2. **После нескольких дней использования:** согласовать изменения формы, истории и хранения.
3. **Отдельными шагами:** несколько счетов и переводы, затем категории и регулярные операции — только после проверки базового сценария.

Аналитика, банковские подключения, кредиты и прогнозы в эту версию не входят.

Оформление вдохновлено init.Tasks и init.Habits; название, интерфейс и исходники приложения самостоятельные.
